# Security policy

Không gửi template có network request, filesystem access, dynamic import theo input, `eval`, `<script>`, inline event handlers hoặc tài nguyên bên ngoài.

Nếu phát hiện template có thể thực thi mã, rò rỉ dữ liệu hoặc tạo SVG nguy hiểm, hãy báo riêng cho maintainer của AIAI Laboratory thay vì mở issue công khai.
