# Repo Garden

Contribution graph trở thành một luống đất lớn. Commit mọc thành chồi hoặc hoa, streak thành dây leo và bốn active repository trở thành cây ở hai bên.

## Data mapping

- Contribution level 1–2 → chồi non.
- Contribution level 3 → cây có nụ.
- Contribution level 4 → hoa nở.
- Longest streak → độ dài dây leo.
- Active repo → cây có tên, language và stars.
- Repo stars → quả phát sáng trên tán cây.

## Options

- `accent`: hoa, quả và nhãn nổi bật.
- `leaf`: màu lá chủ đạo.
- `background`: nền đêm của khu vườn.

Để tạo một biến thể mới, hãy thử đổi loại cây theo language, thêm thời tiết từ tổng contribution hoặc thay dây leo bằng một con đường xuyên vườn.
